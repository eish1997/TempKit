# 图片堆叠与透明画板交互原型

日期：2026-11-12。来源：[IDEA-002](../docs/quickgen/ideas.md)，部分借用 IDEA-001 的常驻开关概念。

入口：[board-prototype.html](board-prototype.html)。本原型独立于桌面生产代码，不替换原有原型，也不改动 W/G 阶段状态。浏览器内以模拟桌面展示透明画板；不是能覆盖其他 Windows 软件的实际原生窗口。

## 本版可以体验

- 主面板顶部露出错位堆叠的图片，悬浮时展开；点击打开/收起画板。
- 全浏览器视口透明画板，首次以网格排列图片在能力面板旁。
- 画板打开时，主面板左侧显示缩略图大纲，上下各超出面板32px，两端各48px渐隐；按加入时间倒序排列，最新图片在最上方，不显示滚动条。
- 画板与大纲同步选中高亮，选中项自动滚至大纲垂直中心（首尾留白允许第一张和最后一张也居中）。大纲和画板图片均可拖入预设；从大纲拖放不改变画板原图位置。
- 滚轮以指针为中心缩放；空白处左键拖动框选（相交即选中），Shift追加框选，单击空白清空选择，Escape取消当前框选。中键或空格＋左键拖动画板；底部提供缩放、还原、重新排列与关闭。框选同步高亮大纲；多选拖入预设逐张创建独立模拟任务。
- 自由移动图片；拖到能力卡片高亮并松手，进入逐张模拟任务队列。原图留在画板，回到此次拖动前的位置。
- 单击能力卡片不生成。没有“先暂存，再点预设执行”的路径。
- 框选后拖动任一已选图片会移动整个选中组，保持相对位置，缩放后仍按画板坐标移动；Escape或指针取消会整组复原。拖动未选图片会切换为单选。多选拖入预设按每张图片分别创建任务，整组原图回到拖动前位置。
- 关闭画板再打开，保留图片位置、平移和缩放；重新排列按钮才显式重排。
- 通过添加图片按钮或外部文件拖入导入本地 PNG/JPG/WebP，可移除图片；文件仅在本地浏览器使用，不上传。
- 可切换深浅主题；常驻开关默认关闭，画板关闭时点击模拟桌面收起主面板，侧边入口可以恢复。

## 暂定选择，不代表最终规格

- 画板操作模式捕获空白区域用于框选/平移；桌面穿透模式保留图片显示并将鼠标操作交给模拟桌面。
- 固定右侧主面板展示；暂不覆盖顶部/左右贴边布局及多显示器。
- 示例使用现有场景插画，所有操作图标使用 Lucide 0.468.0；无真实生成结果。
- 已确认多选拖入预设为逐张生成，不作为多图联合参考；原型队列暂按串行执行。
- 本地导入暂设每张20 MB；此值仅为原型限制，不覆盖生产版限制。画板现场保存在当前浏览器、当前站点的 IndexedDB；清除站点数据会丢失现场。
- 顶部“交互原型”标记位于演示环境，不是产品面板的常驻提示。

## 逐张生成流程（2026-11-12）

- 每张输入创建独立任务，排队 → 模拟生成中 → 结果或失败；一个失败不会阻塞后续任务。
- 提交时在各自原图附近预留无重叠位置；完成后结果替换该占位，原图及画板相机保持不变。结果以完成时间加入大纲和顶部堆叠。
- 失败占位提供独立重试，重试复用同一任务/结果位置，不重复执行已成功项。关闭画板不停止队列，重开可查看结果。
- 演示栏“下次首张模拟失败”只作用于下一次提交的第一张，用后自动关闭；重试默认成功。
- 模拟结果复用输入图像并标注“模拟结果”，没有模型调用、网络上传或费用；刷新恢复内容，未完成任务标为已中断，需手动重试。

验证：浏览器真实框选两图并拖到预设，观察到一项处理中、一项排队；首项模拟失败后第二项完成；单独重试首项后恰有两张结果、零待办，原图位置不变；关闭重开保留结果，大纲最新项为最后完成结果。浏览器错误日志为空。截图：board-prototype-results.png。

顶部堆叠增量：显示0—4张真实图片，最多显示最近4张图片；清空后不补占位图，按鼠标横向位置逐张抬起约32px并回正，露出更多图像；可直接将当前图片拖到预设，画板未打开时也能提交单图任务，拖放后不会误触开关画板。已通过浏览器实际拖放验证，并确认单项结果生成。

## 任务控制与本地恢复

排队和运行中任务可取消；取消通过执行次数令牌使旧回调失效。失败、取消和中断项可重试或移除。恢复图片（导入图像内容随状态保存）、图片坐标、缩放/平移、选择及任务记录；运行和排队项恢复为中断，避免自动重复执行。保存失败显示提示。此存储属于浏览器原型，不是桌面应用持久化。

浏览器验证：同时提交两图，分别取消排队和运行项；刷新仍保留取消状态、4张原图及120%缩放。移除一个任务后重试另一个并立即刷新，恢复为中断、未自动生成。尚未验证浏览器进程重启、存储配额耗尽及本地文件导入后的恢复。

## 画板操作与桌面穿透模式

- 底部显示器图标切换到穿透模式，图片保持位置和缩放，图片、大纲停止接收操作；大纲隐藏。未常驻主面板收起，常驻面板保留可操作。
- Alt＋·（数字1左侧的 Backquote 键，按物理键位识别）双向切换，长按不重复触发；底部恢复按钮或右侧刘海入口也可恢复画板操作，保留现场。快捷键仅在当前网页获得焦点时生效，尚不是系统全局快捷键。
- 模拟桌面提供素材文件夹、便签、场景预览三个可点击入口，可打开内容、输入文字、切换场景和关闭窗口，用于验证点击是否穿过图片浮层。
- 穿透时鼠标覆盖的图片以160ms淡至30%不透明度，移开恢复；退出穿透或鼠标离开页面清除透明状态。图片仍不接收点击，底层桌面可操作。已验证悬浮透明度0.3、pointer-events为none，以及快捷键恢复后透明状态清除。
- 浏览器已验证穿透打开便签并输入、快捷键恢复画板、未常驻收起和常驻保持显示。截图：[桌面穿透模式](board-prototype-desktop-mode.png)。真实 Windows 窗口穿透和全局快捷键仍需桌面宿主实现。
