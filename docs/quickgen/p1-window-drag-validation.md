# QuickGen Windows 桌面验收矩阵

更新：2026-11-11，包含后续主题及原生圆角/间距要求。规则来源：[最终交互规格](interaction-spec.md)。进度唯一记录在 [桌面开发计划](windows-desktop-plan.md)，本表只定义验收，不表示已通过。

## 环境与证据

每次记录源码/构建标识、实际启动路径、Windows/WebView2/Tauri 版本、显示器与缩放、动态效果模式。先确认运行的是该候选，旧页面/错误服务不能作为证据。默认验证当前开发机，不能外推所有 Windows 版本。

每项证据记录：输入与操作、预期、实际、通过/失败/待验证、截图或录屏路径、候选身份。自动检查不能替代原生窗口、资源管理器拖放、透明区域穿透和动效体验。

## 验收矩阵

| ID | 阶段 | 操作与通过标准 |
| --- | --- | --- |
| ENV-01 | W1 | 开发与构建候选均能启动、明确退出；记录版本、路径、日志和运行命令 |
| WIN-01 | W2 | 入口顶部初始居中，可拖动贴靠顶/左/右并保持置顶；拖动不误触点击 |
| WIN-02 | W2 | 点击入口由同一形体生长为面板，展开后无独立刘海；X 收起后入口存在、进程不退出 |
| WIN-03 | W2 | 点击入口及面板以外的透明区域能操作后方软件，不能存在不可见遮挡矩形 |
| WIN-04 | W2 | 默认 280×220 两列；四边四角均可调，最小 120×120 单列；控件和暂存缩略图不溢出；隐藏滚动条但可滚动 |
| WIN-05 | W2 | 顶/侧边和靠近角落展开不越界；当前可用显示器/DPI 配置下坐标正确；不可测配置明确待验证 |
| MOT-01 | W2 | 正常模式录屏/逐帧可见轮廓、背景、圆角连续变化；卡片无拉伸、固定边框闪现或整页硬切 |
| MOT-02 | W2 | 快速展开/收起能够反向衔接，拖动调整不滞后；隐藏控件不截获输入 |
| MOT-03 | W2 | 减少动态效果模式保留温和淡入淡出；显式完整预览独立验证，不修改系统偏好 |
| UI-01 | W2 | 高度图标上下拖动与方向键/Home/End 可切换四档、实时更新，无菜单和档位文字 |
| UI-02 | W2 | 标题行主题图标循环跟随系统/浅色/深色，主面板和已打开的附属面板同步；120px单列及暂存缩略图同时存在时不溢出；全部控件6px圆角，二级原生窗口外框也为6px |
| DROP-01 | W3 | 从资源管理器拖 PNG/JPG 至刘海原地松手：展开、暂存、缩略图可见，无能力触发；随后点击卡片恰好触发一次 |
| DROP-02 | W3 | 展开完成满1秒后，从刘海继续拖出入口到卡片松手，以及直接拖到已展开卡片，均记录正确文件和能力且只触发一次；不足1秒松手只暂存，即使图片解码完成时已超时也不自动触发 |
| DROP-03 | W3 | 展开期间指针不动，卡片出现在指针下方后松手，仍只暂存；顶部、侧边都验证 |
| DROP-04 | W3 | 空白处放下新图片替换暂存；收起重开及打开添加/库后仍保留；无图点卡片不发起任务 |
| DROP-05 | W3 | 未知悬停 MIME 不被直接拒绝；松手校验真实文件；TXT/PDF、损坏图、多文件不崩溃、不覆盖旧图片 |
| DROP-06 | W3 | 取消、离开、重新拖入、触发记录后再次拖入均正常，无残留命中高亮或旧任务误触 |
| DROP-07 | W3 | WebP 重复两条输入路径；失败记录格式兼容缺口，不混同 PNG/JPG 通过 |
| CAP-01 | W4 | 添加与预设库各自作为非模态小面板贴主面板；内容区相隔12px、移动跟随、空间不足换侧；X 只关闭自身，主面板收起一并关闭 |
| CAP-02 | W4 | 有效名称/指令与可选封面生成卡片；空白/过长/非法封面拒绝；取消不新增；预设按 ID 防重复 |
| SAVE-01 | W4 | 修改位置/尺寸/卡片高度/能力/主题后退出重启恢复；待处理图片不恢复；移除源封面文件不影响副本 |
| SAVE-02 | W4 | 使用测试配置验证写入失败反馈和损坏恢复；保留坏文件，不破坏用户配置 |
| END-01 | W5 | 交付候选从启动、贴边、展开、两条拖入、能力添加、收起、退出到重启恢复完整走通；证据关联同一构建 |

## 门槛与不包含项

WIN、MOT、UI、DROP-01 至 DROP-06、CAP、SAVE、END 是阶段完成门槛；不能用语法检查或模拟 DOM 事件替代系统拖拽。缺真实测试的项目保持待验收。WebP 缺口单独公开，不把未支持说成支持。

对 Maya、UE 或 Nuke 做一次向外拖拽探测，记录来源软件、版本、操作与收到的文件路径/位图/空数据；设备或软件不可用则记录原因。DCC 视口外拖失败不否决核心验证，第一版仅承诺已导出的图片文件。

不要求模型请求、真实生成、结果自动保存/复制/拖出、任务队列、历史、SQLite、多图、跨平台。模拟触发不得显示“已保存”。任务栏按钮数量记录实际表现，不预设窗口个数作为失败条件。

真实模型、生成状态和结果文件的验收见 [G 阶段计划](generation-plan.md)，不回填为 W 阶段已实现。UI-02 属于后续新增要求，其实现/自动检查和桌面实际确认分开记录。
