# QuickGen Windows 便签集成候选

便签集成 N0—N5 的行为验收已完成，交付程序 SHA256 为 50989457BDB25A48F49F68195DCB9CF390ACDFFF4B0D8B505687C6DD816A3969。证据及适用范围见 notes-integration-plan.md。保留日常程序和数据，不自动安装或替换日常程序；本轮没有迁移生产数据。

测试启动：`QuickGen.exe --isolated-data "D:\QuickGen-notes-test"`。使用绝对路径和独立测试目录，不将生产目录作为测试目录。需要 Windows x64 与 WebView2 Runtime；启动前退出其他 QuickGen 实例以释放热键。

右键叠纸入口新建便签，空白便签也保留。左键进入总览，点击卡片切换常驻；拖动平移、滚轮缩放，Esc 或再次点击入口退出。

常驻表示退出总览后显示；置顶独立控制覆盖其他应用。收起保留内容；删除后在面板下方撤销，撤销立即恢复常驻显示。头部可拖动，右下角把手调整尺寸；更多菜单包含删除。

Alt+F4 作用于便签时收起，作用于主窗口时保存并退出。保存失败保留草稿并报告错误；意外终止只能保证恢复已确认提交的内容。托盘恢复副本包含图片、模拟任务、场景和便签。

不自动导入浏览器原型内容，不调用付费模型或真实 Harness。只换旧 exe 不能无损读取新版数据库。此包不含用户数据或开发工具。

已验证 125% / 100% 双屏往返、断屏找回及单窗口关闭。容量证据覆盖 100 张便签、10 个驻留窗口、30 分钟；后续呈现修复另有 60 次切换及原生体验回归。保存确认曾出现 3.30 秒峰值；末段内存趋稳约 821–825 MiB，不代表无限容量或长期无泄漏保证。
