# QuickGen 富文本便签与桌面画笔候选

本说明对应 M0—M8 迁移版本。程序身份以包内“构建信息.json”和 SHA256SUMS.txt 为准；自动验证、容量结果和原生待验收见 notes-integration-plan.md 第9节。旧 N 阶段验收不能替代本轮新增交互的实际桌面验收。候选不自动替换日常程序或迁移日常数据。

解压整个包，使用“启动隔离候选.cmd”。脚本为该包建立独立测试目录，可与日常版并存；请勿直接双击 QuickGen.exe，否则会使用日常数据目录。需要 Windows x64 与 WebView2 Runtime。隔离实例不占用全局 Alt＋·，日常版该快捷键保持原规则。

## 便签

右键叠纸入口新建，左键打开总览。新建时在当前屏幕优先找空位，空间不足时错开排列；已有便签不自动移动。总览点击卡片切换常驻，拖动平移、滚轮缩放；Esc 或再次点入口退出。常驻控制总览关闭后是否显示，置顶独立控制窗口层级。收起保留内容，删除后可在面板下方撤销。空白便签同样保留。

工具栏支持加粗、高亮、待办、引用、分割线、标签和清除格式；支持撤销/重做。跨段待办按逻辑段落转换，引用里的待办可以划除。选中文字点标签，或输入 #名称 后按空格/Enter 创建。双击标签改名，单击换色，悬停查看日期；日期由宿主确定，改名换色不重置。退格可还原为 #文字。

引用块对应左边纸质侧签：点击定位，拖出或右键复制纯文本。滚动时只显示完整侧签。主题按钮提供普通色和纸张主题；主题与正文独立保存。总览采用轻量摘要，不为每张卡片创建编辑器。

## 桌面画笔

点击面板底部铅笔拿起画笔：原位置的笔隐藏，入口与绘制光标统一为系统 ✏️，笔尖为落笔点；面板下方出现七色、三档线宽。再次点击原位置或按 Esc 放回画笔。已展开的画板保持显示，可直接在其上标注。左键画点或线，按住 Shift 保留直线端点；双击空白创建描边文字，双击文字再次编辑。Enter 提交、Shift+Enter 换行、Esc 取消文字编辑，组合输入结束前不提前提交。

右键面板铅笔按钮可清空所有屏幕上的临时标注，保留为一次撤销；退出绘制后也能清空，重新开启画笔按 Ctrl+Z 可恢复。清空未确认时保留错误和重试入口。画笔统一显示在便签和画板上方，笔迹不为便签或画板留空洞；绘制时它们下方的操作由画笔接收。只有画笔按钮、色宽条和必要提示等控制区保持可点击。退出绘制后笔迹仍显示在上方，鼠标穿透，可正常编辑下面的便签和画板。

按住右键擦除时，笔翻转到橡皮端；松开恢复笔尖。中键移动时显示系统 🤏 捏合手势，松开恢复。

在当前屏幕的绘制区域按住鼠标中键拖动，可平移最近画出的一笔或最近输入/修改的文字，不必点中它；松开后记作一次撤销。只移动当前屏幕上的单个标注，不跨屏搬运或改变内容、颜色、线宽。

按住右键拖动，擦除触碰到的整条笔划或整段文字；一次拖擦对应一次撤销。Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做，最多100步。点击铅笔或在绘制区域按 Esc 退出。退出后标注仍显示且鼠标穿透，重新打开可继续编辑。

画笔是当前会话的临时标注：退出整个程序或异常终止后不恢复，不混入便签/图片/恢复副本。颜色和线宽会记住。提交未确认会保留当前草稿，显示重试和明确放弃入口；正常退出会等待编辑确认，失败保留程序以供处理。

## 保存与验收边界

便签正文防抖保存；收起、总览、导出、正常退出会等待保存屏障。失败保留草稿并提示重试。异常退出只能保证已确认提交的便签，未确认编辑可能丢失。不要清空数据库或 WebView 缓存解决保存错误。

旧纯文本升级为结构化文档，保持换行和其他字段。未来格式只读显示，不静默压平。恢复副本包含完整便签、主题、标签、引用和原有资源/任务；恢复必须先核对清单并在副本上进行。详见随包“备份与恢复.md”。

未新增模型调用或完整预设编辑器，原任务快照、费用额度、连接安全存储和设置草稿保护继续生效。默认网页右键已禁用，自定义菜单保留。原先添加连接的 invalid credential value 手测问题仍未定位，不因本轮便签验证视为解决。

本轮集中原生待验收：中文系统输入法与标签操作、跨应用侧签拖出、物理绘制/右键拖擦及退出后点击其他应用、125%/100%多屏和断屏重接。自动事件、独立桌面窗口状态及无头浏览器截图均不能替代这些操作。具体自动结果和负载范围以最终执行台账为准。

本轮自动验证覆盖旧库升级、读写失败及重试、已确认保存后异常终止、完整恢复副本重开。容量负载为100条混合富文本、10个驻留编辑窗、500条笔划及50段文字，持续编辑、擦除、撤销和切换总览30分钟。采样分别记录完整进程树私有内存、工作集求和、保存确认耗时及画布CPU提交耗时；这些指标不等于实际物理内存独占量、系统输入延迟或屏幕帧率。

集中手测可按以下四串动作进行，不需要配置模型连接：

1. 用系统中文输入法编辑普通与纸张便签，跨段加待办、引用、标签，改名换色后收起再打开，确认内容保留。
2. 点击、滚动引用侧签，拖一段文字到常用输入框；缩窄窗口并切换主题，检查菜单和工具栏。
3. 开启画笔，画线、双击创建与修改文字，按住右键擦除并撤销；退出画笔后点击下面的其他应用，确认穿透。
4. 有条件时测试不同缩放比例的显示器及断屏重接；正常退出隔离候选再重开，确认便签保留、临时画笔清空。
