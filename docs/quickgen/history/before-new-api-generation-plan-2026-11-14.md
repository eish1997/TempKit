## 独立服务交付与验收补充

- G0确认网关代码位置、技术栈、版本化协议、输入传输/大小限制、调用与结果保留、部署启动方式。首期允许本机独立运行，不要求共享QuickGen进程、目录或数据库。
- Gateway具备产品身份隔离、产品密钥与服务商凭据分离、明确模型路由及调用记录。QuickGen继续拥有业务队列、资源和场景；网关不接管产品任务。
- 使用两个独立测试客户端身份验证可复用性与越权拒绝，无需新做第二个产品。适配器用假服务测试请求转换/异常，不为证明扩展性强制付费接两家供应商。
- 验证同幂等键复用、冲突拒绝、跨产品访问拒绝、响应丢失后的查询、网关重启、结果过期和归档失败后不重新生成。未知受理状态停止自动重发。
- 网关与QuickGen分别记录版本、构建/启动说明、验证证据和接口兼容性；网关离线不影响本地收纳查看。
- 网关结果需被QuickGen实际下载、校验和归档；返回URL或网关成功状态不能代替产品结果保存成功。

## 交付要求

UI只展示宿主权威任务状态；模型无进度就不编造百分比。远端生成成功与本地归档失败分开；临时URL不能称为已保存。任务中收起界面不取消任务；重启未知状态不自动重发。每张任务独立重试，用户原图不覆盖。

复制/拖出在此阶段是必做交付，不再被放到无限期后续；复杂项目管理、通用工作流、多模型自动编排、云同步不在范围。服务适配测试不能替代真实服务和真实目标软件证据。用户本轮仅授权文档统一，不据此自动开始G开发或付费调用。
