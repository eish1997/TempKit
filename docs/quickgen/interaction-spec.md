# QuickGen 最终交互规格

更新：2026-11-13。本文件统一当前产品交互；当前交付与验证边界见[桌面基线](desktop-baseline.md)，下一阶段见[资源与任务计划](resource-task-plan.md)。W阶段文档仅保留历史证据。

[画板原型](../../design/board-prototype.html)仅作视觉参考，未通过的实现不能反过来覆盖规格。Figma 不作为当前版本来源。

## 阶段与边界

### 当前单屏画板交互

以下已迁入单屏桌面版；真实执行仍为模拟。迁移过程见[迁移计划](board-migration-plan.md)。

- 主面板收起按钮改为常驻开关，默认不常驻；同组画板/能力/附属界面操作不误收起，离开操作范围后收起，重开保留现场。
- 顶部显示最近0—4张真实图片，不补占位、不显示数字；按鼠标位置抬起对应图，可拖到能力卡。
- 画板支持缩放、平移、左键空白框选、Shift追加、组拖动；首次整齐排列，重开不重排。
- 大纲位于主面板旁，按加入时间倒序；与画板选择同步且当前项居中，上下可超出并渐隐。画板/大纲均可拖到能力卡。
- 多图拖到能力逐张独立执行；原图保留，结果在原图旁，可再次拖入能力。移除“暂存后单击能力生成”。
- Alt＋·（数字1左侧键）切换操作/桌面穿透。穿透保持图片可见，未常驻面板收起，常驻仍可操作；返回保留相机/选择/布局。
- 穿透时鼠标覆盖图片半透明，移开恢复，点击仍交给后方软件。暂用30%不透明度、160ms过渡，减少动态效果时立即切换。
- 桌面必须使用全局快捷键，冲突须可恢复；浏览器页面内快捷键不算桌面验证。

旧单图暂存规则仅描述W候选，不是画板目标。资源管理器落到收起入口/新展开面板的1秒防误触保留；画板内有意拖到能力不重复添加此延迟。

整体结构见[架构](architecture.md)，下一阶段见[资源与任务计划](resource-task-plan.md)，之后见[真实能力计划](generation-plan.md)。本文未来交互约定不表示功能已经实现，也不自动授权模型调用。

当前已实现的范围是 Windows 桌面验证，采用 Tauri 2，窗口数量由验证决定。需要真实窗口、文件拖入、用户能力集合与配置恢复；不接模型，不实现真实生成/自动保存/复制结果/拖出结果。

浏览器原型中的固定结果图、“已保存”和无图点击卡片均为旧演示行为，不是桌面验证的通过标准。当前桌面有图拖放进入前端模拟串行队列，结果复用输入并明确标为模拟；点击能力不发起任务。

## 入口、展开与尺寸

| 项目 | 当前规则 |
| --- | --- |
| 入口 | 初始顶部居中，顶部约 88×18，侧边约 18×88；可拖动到顶部、左侧、右侧并沿边调整位置 |
| 形体 | 入口自身向内生长为面板，展开后不留独立刘海；收起沿原路径回到入口 |
| 主面板 | 默认 280×220，最小 120×120；默认两列，窄到单列，列宽至少约 100px |
| 调整 | 四边和四角都可调整宽高；顶部/侧边贴靠时保留锚点，尺寸受可见屏幕约束 |
| 移动 | 拖入口或操作行空白处；拖动结束不能误触点击；不显示拖手图标 |
| 收起 | 操作行是常驻开关，默认不常驻；离开焦点组后自动收起，附属面板一起隐藏；重开保留现场 |
| 输入区域 | 置顶；入口/面板之外的透明区域不拦截后方软件的鼠标操作 |
| 滚动 | 隐藏滚动条，保留滚轮、触控与键盘滚动；不允许内容溢出到桌面 |

尺寸按逻辑像素描述，原生实现负责 DPI 换算。显示器或缩放变化后位置必须落在可见区域。主面板收起不同于退出进程；操作行不放退出应用按钮，避免误关。聚焦主窗口后 Alt+F4 保存布局并退出，须实际验证。

## 操作行与能力集合

操作行约22px，无标题，提供画板、自定义添加、预设库、卡片高度、主题和常驻图标；图片以面板顶部0—4张堆叠表示。最窄120px时控件不溢出，不取消操作。应用使用系统托盘，不占任务栏；托盘可打开面板和退出。

面板展示用户添加的能力，初始使用白模转写实、材质替换两张示例。卡片为整面图片，标题叠在图上，无文字底条、独立拖放区或生成按钮。

卡片高度为 32/56/80/112px，默认 80px。直接上下拖动操作行高度图标，上拖变矮、下拖变高，约每 22px 切换一档并实时预览；松手仅图标轻弹回位。不打开菜单/浮层，不显示档位文字或圆点。支持方向键、Home/End 与无障碍数值。

## 自定义添加与预设库

两者均为独立、非模态小面板，宽约 308px，自定义默认高 312px、预设库默认高 344px；空间受限时压缩窗口并允许内容滚动。与主面板内容区相隔 12px，优先在右侧顶端对齐；空间不足换到左侧或上下方，必要时允许部分覆盖，但始终以主面板定位，不居中、不吸附屏幕边缘。主面板可操作，移动时小面板跟随。同一时刻最多显示其中一个。

两者右上角均为 Lucide X，仅关闭对应小面板。关闭/取消自定义表单不新增卡片；关闭预设库不撤销已经添加的能力。

自定义字段：名称必填、最多 24 字；处理指令必填、最多 2000 字；可选 PNG/JPG/WebP 封面、最多 5 MB，无封面使用默认图。添加成功即加入面板。字段须拒绝纯空白值。

预设库包含下列能力，按需添加，通过稳定预设 ID 防止重复；已添加项不可重复添加。能力说明作为内容保留，不是操作提示。

| 能力 | 含义 |
| --- | --- |
| 白模转写实 | 白模场景转为写实效果 |
| 材质替换 | 修改物体材质与表面属性 |
| 角色精修 | 优化细节、质感与外观 |
| 场景氛围 | 调整灯光、天气与环境 |
| 图片扩展 | 扩展画面边界与构图 |
| 风格迁移 | 转换视觉风格 |

## Harness快捷添加（规划，未实现）

用户在自己的Harness中说“添加到QuickGen”，由Harness提交已跑通能力的引用、名称与参数，QuickGen校验后新增卡片。首次建立连接或新增权限需要必要授权，已信任连接下不要求重复手填接口。导入本身不执行能力。

卡片后续经原Harness执行，默认固定能力版本。离线显示不可用并提供重连；版本缺失不得静默替换。添加失败不显示为可用，重复添加不产生重复卡片。具体连接方式待选定Harness后确定；参见[架构](architecture.md)。

## 图片输入状态与触发

当前接收PNG/JPG/WebP，每张上限20MB；支持多图逐项校验，错误项不覆盖已有图片。类型声明不代替真实解码校验。

| 操作 | 结果 |
| --- | --- |
| 外部图片悬停收起入口 | 展开，不执行能力 |
| 入口、面板空白处松手 | 导入画板，仅收纳 |
| 外部图片落到卡片，展开完成不足1秒 | 仅导入画板，不执行 |
| 外部图片落到卡片，展开完成已满1秒 | 对有效图片逐张创建模拟任务 |
| 从画板、大纲或堆叠有意拖到能力 | 执行，不重复等待外部拖入的1秒保护期 |
| 多张选中图拖到能力 | 每张一个任务，串行执行；保留原图，结果在原图旁 |
| 点击能力卡片 | 不消费收纳图片，不创建任务 |
| 无效或损坏文件 | 简短错误，不清空已有图片和已完成项 |
| 取消拖拽 | 不创建任务，清除投放高亮 |
| 收起重开或重启 | 恢复已保存的图片和场景；中断任务不自动重发 |

悬停阶段文件路径或MIME不可读时，不能仅因此拒绝；松手取得实际内容后校验。外部卡片保护期从展开动画完成计时，期间不显示可接收高亮；按松手时刻冻结资格，不因异步解码跨过期限而变成执行。收起重开重新计时，调整尺寸不重置。

图片移除与执行分开；不再用单个暂存缩略图“点击清除/点击能力消费”的旧模型。未来Rust资源删除与引用回收规则在R0确定，不把移除画板元素等同于删除用户原文件。

## 动效与可访问性

正常模式要求外轮廓、背景和圆角连续变化，卡片不被拉伸；不是切换两张页面，也不能只通过裁切揭露固定边框冒充形变。内容在外形开始展开后再显现，收起回到当前入口位置。快速反向操作应从当前进度衔接，拖动与调整尺寸直接跟手。

当前桌面形变240ms，支持中途反向；键盘快捷切换与系统减少动态效果模式直接完成。历史原型参数不覆盖当前桌面规则。

默认尊重prefers-reduced-motion：取消明显形变和弹性。原型 ?motion=full 是明确的完整动效预览入口，不修改系统设置，也不代表产品默认行为。

## 视觉体系

面板、卡片、按钮和输入框统一圆角 6px（共用 --ui-radius）；字体优先 IBM Plex Sans，其次 Segoe UI。主面板、附属面板、字段、菜单、焦点态和禁用态共用相同令牌。

| 令牌 | 深色 | 浅色 |
| --- | --- | --- |
| 背景 | #141414 | #F4F4F2 |
| 表面 | #1C1C1C | #FFFFFF |
| 描边 | #2A2A2A | #D8D8D6 |
| 文字 | #F2F2F2 | #161616 |
| 次文字 | #8A8A8A | #6B6B6B |

全部操作图标使用本地 Lucide v0.468.0，常规 16px/线宽 1.75，入口 12px；禁止字符拼图标或自行绘制操作图标。卡片场景插画不属于图标。去除悬停、占位、常驻操作说明；保留字段名称、能力说明、错误、功能状态和无障碍名称。

## 本地恢复

桌面阶段保存入口边缘与位置、面板宽高、卡片高度、用户能力及封面。封面复制到应用数据目录，不依赖用户源文件持续存在；配置写入失败须有反馈，损坏时保留原文件并安全恢复默认。当前配置由storage.rs管理，图片、场景及模拟任务由WebView IndexedDB保存。下一阶段迁至Rust资源/任务服务，存储选型在R0确定；旧数据验证迁移完成前保留。

## 后续能力执行（尚未实现）

先迁入Rust资源与任务服务，再接真实模型、Agent或本地工具。预设声明接受的资源类型、输入用途和参数；不兼容输入在执行前拒绝。统一协议不意味着所有资源类型已能预览或处理。

真实图片结果沿用原图旁呈现和再次拖入能力，不新增主面板结果页。粘贴输入、复制结果和文件拖出是后续真实收纳闭环的必做项，目标软件实际接收需独立验证。其他类型的结果按实际能力补相应呈现。

状态由宿主任务服务驱动，不用模拟结果或假百分比替代。执行失败与输出归档失败分别处理，保存重试不得重跑执行器；未知远端状态不自动重发。涉及外部动作的Agent按明确权限与必要确认处理。具体切片见[资源与任务计划](resource-task-plan.md)和[真实能力计划](generation-plan.md)。

## 变更归并记录

本版已移除过时规则：固定顶部居中、固定六张卡片、固定两列最小宽度、右下角单独调整、独立刘海加面板、弹出高度菜单、预设库返回上一级、屏幕居中的二级界面、悬停提示，以及拖到入口后必须重新拖图。历史浏览器实现不作为桌面阶段完成证据。

## 主题选择

标题行主题图标按跟随系统 → 浅色 → 深色循环切换，采用同版本 Lucide monitor/sun/moon。默认跟随系统，手动选择同时作用于主面板及已经打开的附属窗口，保存至独立 theme 配置字段并跨重启恢复；旧配置缺失时默认 system，不重置用户卡片。无悬停提示，保留无障碍名称。

### 桌面画板整合后的交互补充（2026-11-12）

- 刘海到面板沿同一表面生长/收回，240ms，支持中途反向。键盘快捷切换和系统减少动态效果模式直接完成。
- 外部拖图展开面板时，动画完成后再等待1000ms才允许卡片接收。松手时判断资格，异步解码不改变当次落点资格；保护期内只导入画板，不能点击预设消费暂存图。
- 主窗口与添加/预设窗口为同一焦点组，跨组失焦150ms后复查；非固定面板收起时附属窗口一起隐藏，不把焦点抢回主窗口。组内切换不收起。
- 附属面板与主内容保持12px间距，优先右侧，然后左侧、下侧、上侧，最终约束在当前工作区；统一6px圆角。
