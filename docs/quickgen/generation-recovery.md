# 真实模型候选：备份、恢复与回退

更新：2026-11-15。本说明对应G阶段schema14候选，已完成选定流程验收，按已接受的性能限制交付；不代表已获准迁移生产数据。实际候选、源码身份及未测项见随包验收状态.md与构建信息.json。

## 数据与切换

默认数据目录为 `%APPDATA%\com.quickgen.desktop`；隔离候选使用启动参数指定的目录。配置、封面、便签和资源库都需要保留，不要把隔离目录的标记或测试图片复制到生产目录。

资源库的metadata.sqlite保存任务、attempt、场景、放置回执、连接版本、费用规则和预留；blobs保存原图及生成结果，staging保存可恢复接收内容。credentials保存当前Windows用户绑定的加密凭据。不要只复制数据库或只复制图片来代替完整备份。

切换程序前先正常保存退出，确认旧进程结束且资源库写锁释放，再完整复制数据目录。校验文件清单、逐文件SHA256、数据库integrity_check与foreign_key_check；保留原程序、原目录和校验后的副本。先对副本演练，不能用生产数据做故障注入。新程序可能升级数据库；旧版不能识别高版本时应拒绝打开，不要手工降版本或删库强行回退。

## 正常退出与恢复副本

托盘“保存恢复副本”先刷新场景和便签，再导出一致数据库、资源、配置/封面/便签及受支持的待保存结果信息，最后写入校验清单。必须核对manifest.json，未完成的导出不可视为可恢复副本。导出不等于可跨机器直接使用的便携目录；模型凭据需要重新配置。

主窗口Alt+F4与托盘退出都走保存流程。程序正在等待网络，或结果只在内存而没有可验证恢复副本时，会拒绝退出并提示。保存失败时保留窗口和数据；不要强制结束进程来代替保存。

## 任务与结果

- 未开始的任务可以取消；队列恢复不会改变原预设、参数、连接或账号身份。
- 请求可能已发送但结果未知时，任务中断并保留原因，不自动重新生成。当前已验证的同步图片接口不提供经过核验的查询/取消能力，不能保证找回未持久化的输出。
- 已持久化图片或加密下载地址可继续保存；“重试保存”不重新调用生成接口。下载地址可能过期，损坏或缺失的恢复文件不能冒充有效结果。
- 明确“重新生成”是新的执行尝试，可能再次收费。旧版双字段解析失败的任务没有本地图片或地址收据时，换新版不会凭空恢复输出，也不会自动重新提交。
- 隐藏任务不取消执行；场景由宿主任务和持久放置回执恢复。明确移除的结果不会被重载或重启重新插入。
- 实际生成结果与模拟结果按任务原执行器区分；旧误标的真实结果在读取时修正，下一次实际场景保存时落盘。原图、资源ID和放置回执保持。

## 凭据与费用

模型令牌和结果地址使用当前Windows用户的DPAPI保护；凭据还绑定原目录身份。不同机器、用户或路径的复制件可能无法解密，须通过本机连接设置重新保存令牌，不要把令牌写入文档、日志或聊天。

本地预留额度不是上游最终账单。恢复、换程序、换同账号令牌和安装费用规则不重置已预留金额。不要删除费用表或重新建库来获得测试额度。未知结果也可能已计费；以可核验的服务账单核对，不把再次生成当成免费恢复。

## 回退限制

保留新目录和新程序，以校验过的旧副本在独立目录演练旧版，明确旧副本不包含后来产生的任务、便签或图片。当前没有把schema14完整无损逆迁移到旧版或旧IndexedDB的工具。禁止用旧程序直接覆盖唯一新库。生产切换及回退须按具体备份和验证结果另行实施，本阶段没有执行生产迁移。
