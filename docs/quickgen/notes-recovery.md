# 富文本便签与画笔候选保存恢复

本说明对应 M 阶段 schema15、文档 version1；唯一进度和证据在 notes-integration-plan.md 第9节。交付隔离候选不等于生产切换，日常程序与旧包保留。

Rust 资源数据库的 notes 表是便签权威。每条记录含版本化结构化文档、宿主生成的纯文本投影、主题、常驻、置顶、桌面几何、显示器、字段版本和软删除状态。正文/主题/几何/标志分别校验版本；删除与撤销使迟到修改失效。空白记录有效，删除不清空正文。标签首次保存时间另由宿主同事务维护，撤销/重做或改名换色不重置日期。

schema14及以前的纯文本以事务转换为默认主题文档，原换行与字段保留；升级失败整体回滚。旧正文写接口拒绝压平已包含富文本格式的记录。未知未来文档版本保留原记录，并在界面只读显示正文投影和明确提示。

正文防抖提交；收起、总览、导出和正常退出等待保存屏障。读写失败保留草稿并明确报错；异常终止仅保证已确认提交的数据。画笔笔划、文字和100步历史属于会话内临时状态，不落数据库，不进入恢复副本，不在重启后恢复；只有颜色和线宽进入配置。

托盘“保存恢复副本”先等待便签保存，导出数据库快照、inventory.json、受管资源与配置备份；manifest.json 最后写入，记录 databaseSchema=15、noteDocumentVersion=1、noteCount 和文件哈希。缺少 manifest 的目录不算完整恢复副本。

恢复只在副本上演练，按以下顺序操作：

1. 核对导出清单的全部哈希，保留唯一原副本不动。
2. 用同版本程序加 `--isolated-data` 和全新空目录的绝对路径启动一次，再正常退出。这一步创建合法的隔离标记；不能先往未初始化目录放数据库后直接启动。
3. 确认该隔离实例已退出，保留根目录的 `quickgen-isolated-v1` 标记。把刚创建的空 `resource-store` 移到另一个备份位置，再建立新的同名目录，将整份导出的内容复制进去，包括 `metadata.sqlite`、受管资源和迁移备份。
4. 用同一个隔离目录重开同版本程序，检查正文、主题、常驻和其他资源。原恢复副本及刚移出的目录继续保留，不清理真实文件。

不要拿生产目录做测试，不直接打开唯一导出数据库写入。JSON清单本身不是数据库导入器。配置备份的恢复需单独核对，真实凭据仍由系统安全存储管理，不能从普通包或聊天恢复。

正式切换前另行备份匹配的旧程序、配置、数据库和资源，并核验恢复路径。schema15不能只换旧exe无损回退；需要升级前的匹配数据副本，升级后新增内容另行保全，不覆盖回去丢掉。没有逆向迁移器，不自动导入浏览器原型 localStorage。

隔离演练涵盖真实旧库升级、富文本恢复重开、读写故障和已确认提交后异常终止。容量和候选身份见执行台账；这些结果不代表系统输入法、物理跨屏或跨应用拖出已验收。
