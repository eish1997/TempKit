## 1. 目标与基线

把已确认的 Web 便签原型接入现有 QuickGen Windows 正式入口，完成独立便签窗口、可靠保存、常驻切换、无边界平铺画板与统一提示区。不新增独立产品，不重新设计交互。

视觉及操作基准：`design/board-prototype.html`、`design/board-notes.js`、`design/board-notes.css`。截图 `design/notes-canvas-preview.png` 与 `design/notes-empty-hint.png` 用于对照，不替代原生验收。

已核对的源码事实：

- 正式入口为 `desktop/src-tauri/src/main.rs → board.rs`，UI 为 `desktop/ui/board.html / board.js / board.css`，沿用 `com.quickgen.desktop`。
- 当前资源库 `store.rs` 的 schema 为 v6；持久数据由 Rust 管理。现有恢复副本包含 SQLite 与受管资源。
- `src/bin/quickgen-notes-prototype.rs` 是独立原型，使用内存 Vec，采用另一应用标识，没有持久保存；仅借鉴窗口操作，不能作为正式集成基线。
- Web 便签使用 localStorage，不能成为正式版数据权威，也不自动导入浏览器试验内容。
- 正式版 `board_group_focused` 仅包含 main、manager。`syncNative` 的交互区域尚未包含移到面板外的提示区、便签入口溢出部分和便签总览。这些是接入边界，尚未进行原生缺陷复现。
- 当前目录不是 Git 仓库。执行前保存相关源码哈希和副本，不假定可用 Git 回退，不覆盖已有改动。

## 2. 固定产品约定

1. 左键便签按钮：有便签就进入平铺总览；真正零张时不打开空白画板，在面板下方提示“右键便签按钮，新建便签”。全部不常驻仍属于有便签。
2. 右键按钮：新建独立便签，立即可输入，并默认常驻。空白便签也是有效内容，必须保存。
3. 总览容器无标题、操作说明、状态标签、空白占位文字、边框背景及滚动条；便签卡片保留已确认原型的纸张底色、圆角与轻边框。保留便签正文；常驻清晰、不常驻变淡，鼠标悬停适度提亮。
4. 总览拖动平移视角，滚轮围绕鼠标缩放。点击便签只切换常驻；拖拽结束不误触点击。总览位置与桌面窗口位置分开。
5. 再点入口或 Esc 退出，恢复常驻便签的桌面位置与尺寸，不常驻便签隐藏。退出不删除任何内容。
6. 图标沿用两张紧凑叠纸、越出面板边缘的造型与前层推近摆正、逐行手写动效。正式版遵循减少动态效果偏好，不带原型的“完整动效”调试开关。
7. 提示统一显示在主面板下方，间隔以原型的 6px 为基准。新建后解除空状态提示，恢复原有任务信息；不另设便签 toast。
8. 独立便签保留原型已有编辑、移动、缩放、收起、置顶、删除与撤销。常驻表示退出总览后仍显示；置顶表示覆盖其他应用，两者独立。普通常驻窗口可被其他应用遮挡；不做 Explorer 桌面嵌入。
9. Alt+F4 作用于便签时等同收起，不退出整个 QuickGen；退出应用仍走现有保存与托盘生命周期。

本阶段不做富文本、搜索、分类、颜色选择、提醒、同步、AI 功能、快捷键扩展或安装器。保留现有图片及任务能力，不将 Gateway/G 阶段并入本计划。跨屏无限画板暂不纳入；屏幕断开后窗口必须能回到可见工作区。

## 3. 接入方案

### 数据与保存

在现有 SQLite 中增加便签表，复用存储工作线程与恢复边界；执行时核对最新 schema，按下一版本迁移，不写死与其他工作冲突的版本号。建议字段：id、text、resident、always_on_top、桌面逻辑坐标/尺寸、显示器标识、revision、创建/更新时间，以及可撤销删除所需状态。

Rust 是唯一权威。编辑窗口按 note_id 更新，宿主校验窗口身份，禁止任意窗口改写其他便签。文本、几何、常驻分别更新，避免全对象旧快照互相覆盖；同字段更新校验 revision，迟到响应不能覆盖新输入或复活已删除便签。提交成功后广播变更，前端只更新对应记录。

输入短暂防抖合并；输入法组合过程不重绘文本框。收起、切入总览、退出、导出恢复副本前等待未完成写入。失败保留草稿、在统一提示区报告并提供可恢复路径；不能以隐藏窗口或显示成功掩盖失败。非正常终止只承诺恢复已确认提交的数据，未提交字符的损失窗口必须在验收记录中明确。

### 窗口与总览

独立编辑使用一个便签一个原生 WebView 窗口；非驻留窗口按需创建或隐藏，避免启动时为每张历史便签创建 WebView。复用原生移动/缩放，保存逻辑坐标并夹紧到有效工作区。无单独任务栏入口，宿主统一管理退出和隔离数据路径。

总览优先复用现有主透明画板，通过显式模式区分图片视图和便签视图；保存进入前的图片相机、选中、穿透及显示状态。先提交便签编辑，再暂时隐藏独立窗口，渲染轻量总览卡片；退出恢复窗口及原模式。Esc 优先结束当前便签总览，不误关主面板。窗口创建失败时保留数据并可重试，不能显示虚假的成功状态。

核对 `board_view`、原生命中区域、焦点组和失焦收起：便签入口越界部分及提示区可点击；进入总览可捕获拖拽/滚轮，退出后桌面空白区域仍可穿透。便签间切换不能被误判为整个应用失焦；不为保持面板打开而让总览永久遮住桌面。

### 统一提示

将任务状态与便签提示通过同一个提示控制器渲染。优先级：未解决保存错误 > 可撤销操作 > 空状态引导 > 任务摘要。消息有来源与标识；解除某条提示只能清除自身，不抹掉另一窗口的错误。任务刷新不覆盖当前有效引导；引导关闭或新建完成后恢复任务摘要。提示区迁出面板后同步更新原生命中矩形、贴边布局和工作区约束，靠近屏幕底部时整组上移以保证可见。
