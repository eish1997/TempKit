# New API 接入、调用额度与结果恢复

更新：2026-11-15。普通候选0787完成选定gpt-image-2真实流程及原生输入输出验收，按已明确接受的性能限制交付。具体范围见 [执行计划](generation-plan.md)。原可靠底座和便签旧包不因此变成支持真实模型的新版本。

## 启动与范围

候选包需要Windows x64和Microsoft Edge WebView2 Runtime。解压完整目录，先正常退出已有QuickGen，再运行QuickGen.exe。默认使用当前Windows用户的原数据目录，不是隔离便携版；0787已通过真实请求期间的桌面刷新与便签体验验收；本阶段未覆盖日常版本或迁移生产数据，正式切换仍须先备份验证。程序不添加开机启动，不包含调用令牌或用户图片。

## 接入顺序

1. 在“预设库 → New API 连接”保存地址、账号名称和模型调用令牌。令牌仅填本机密码框；不要放入聊天、预设提示词或截图。账户管理令牌不等同于模型调用令牌。
2. 点击“检测连接”。认证通过、模型列表可见只证明连接与发现接口可用，不证明图片编辑协议、费用或结果接收已验收。
3. 在“预设模型绑定”选择预设、连接和准确模型 ID，按渠道支持填写尺寸、质量和返回方式。当前选定模型为 `gpt-image-2`，测试配置为 `1024x1024` / `low` / 使用服务默认返回方式；这不是其他渠道的通用配置保证。
4. 在“调用额度”明确保存本地总额度。最多六位小数，保存后本阶段不能重置或提高。页面显示总额度、已预留和可用金额；这些是本地保守预留，不是上游账单。仅保存额度不会调用模型，也不会跳过宿主的模型费用核验。费用未核验、批准过期或余额不足时不发送请求。

同一账号续换令牌时，可在连接条目选择“更换同账号令牌”，填写原账号名称和新令牌。地址、账号与旧任务目标不会更改；运行中的请求保留已取得的原令牌，待执行请求必须等新令牌重新检测通过。账号归属由用户确认，检测成功只证明认证可用，不能证明两个令牌属于同一账号。不同账号应新建连接。轮换历史中的加密凭据保留至撤销连接，撤销会尝试清除全部版本。0F77的入口外观已取得原生通过反馈；真实账号令牌未实际更换，自动隔离轮换证据见执行计划。

更改绑定不会改写已有任务的模型和参数快照。解除绑定后，新任务回到模拟执行；已有任务与结果保留。撤销连接不会取消已经发送的上游请求。

## 放入与取出

主面板或图片画板获得焦点后，Ctrl+V 收纳剪贴板图片并打开画板，不自动执行任务。便签正文和表单中的文字粘贴继续使用原来的文本输入行为。

把图片主动投给预设才受理任务，多图逐张处理。选中单张图片后 Ctrl+C 可复制图片；按住 Ctrl 从图片画板拖到桌面或文件夹可复制文件。无需 Alt 再加 Ctrl。拖出过程中 Esc 取消后，QuickGen 恢复，原图保留。实际目标软件和手势验收范围见执行计划，不能由内部 DOM 测试代替。

## 隐藏、取消和删除

| 操作 | 含义 |
| --- | --- |
| 取消排队任务 | 阻止尚未开始的任务执行；已经发送的请求不承诺可撤销 |
| 隐藏任务 | 仅隐藏卡片，不取消执行、不删除结果；结果恢复由宿主持久任务及放置记录驱动 |
| 移除画板结果 | 删除其画板放置；保存后重载、重启不会再次自动插入。它不等同于立即物理清除所有资源文件 |
| 重试保存 | 只继续下载已返回的结果或归档，不重新调用生成接口，不增加执行次数 |
| 重新生成 | 会产生新的执行尝试，可能再次计费；不能用来替代保存失败的恢复 |

## 失败与退出

“结果保存失败”时保留原图，使用任务卡或提示区的“重试保存”。已接收但尚未完成归档的结果会保留恢复记录；隐藏卡片或重载 WebView 不应丢失这条恢复路径。

当前已验证的渠道可能同时返回图片数据和下载地址；修复版优先接收图片数据，不重复下载同一结果。成功落盘前遇到无法解析的响应，若渠道没有结果查询能力，本地可能无法找回；A913的两条此类失败记录保留，不自动重发。

上游是否受理不明的任务不会自动重新生成。下载地址过期、恢复文件损坏等情况可能无法继续下载；不要把新生成当成免费的恢复。保留原数据和错误记录后再决定下一步。

正常退出会先保存场景、便签并检查任务。请求仍在途，或结果只在内存且尚无可验证恢复副本时，会拒绝退出并提示。已经校验过的持久图片或加密结果地址可在退出后恢复；这不保证服务端地址永不过期。看到保存失败提示时不要靠强制结束进程替代保存。

## 暂存维护与恢复副本

“New API 连接 → 暂存空间”区分接收暂存和拖出副本。清理不会删除受保护的待保存输出。拖出清理每批最多核验 32 MiB / 64 个文件，正在占用、已修改或未完成的文件会保留；先确认目标软件复制完成，再执行页内确认。

“备份并移出”先复制、同步和核对清单，再移出允许处理的文件。它仍占磁盘空间；打开恢复目录后可检查文件和 `manifest.json`。拖出文件备份、接收遗留文件备份都不是完整用户数据备份。

完整恢复副本使用托盘“保存恢复副本”，包含数据库、资源、任务、场景、便签及可验证的待保存结果记录。保留完整目录和原数据，不要只拷一个数据库文件或删库强行降级。具体迁移与回退步骤见 [备份与恢复](recovery.md)。

模型调用令牌使用当前 Windows 用户的 DPAPI 加密，并绑定凭据目录身份；完整恢复导出不包含可直接迁移的调用令牌。更换目录、Windows 用户或机器后可能需要重新配置连接。加密结果地址也不能视作跨用户通用恢复文件。不要把旧凭据文件复制到新目录后假定认证仍可用。

## 当前限制

费用规则安装已在普通候选A913通过实际命令隔离验证，后续B991已包含此入口。它是宿主离线维护命令，不是要求用户再填一次总额度，也不会自动发送生成请求。规则必须明确绑定版本、人民币单次上限、有效期、计价依据及允许的尺寸/质量、提示词字节数、输入图片宽高和字节数。超范围请求拒绝发送；不能把文档中的平均输出价当作含编辑输入与网关重试的完整上限。

新入口为 `quickgen-desktop.exe --isolated-data <隔离目录绝对路径> --install-image-cost-rule <已复核规则JSON路径>`。仅用于本阶段隔离目录，须先正常退出宿主、备份并验证数据；运行中的写锁会拒绝安装。文件不包含令牌。安装规则不重置总额度、不清除已预留金额，也不会使已受理任务重新执行。本轮已安装限定测试范围的规则；其中每次¥0.50是保守测试预留，不是服务商保证的价格。不提供可直接照抄为正式收费依据的数值。

本阶段普通交付候选为0787。两张输入批次成功、结果再次处理与Ctrl拖回桌面文件夹均通过。累计授权上限¥3.50，累计7次真实请求，服务计价0.099064 PTC；不能冒充人民币实付。测试保守预留已用完，未自动释放或重置额度；后续调用须重新核对授权、计价与有效规则。

性能数据必须在同一存储位置比较：现有 C→F→C 隔离测量发现 F 盘持久化明显更慢，具体系统原因未确定；这不等于已经解释或修复所有桌面卡顿。不要为了测试速度擅自迁移真实目录或降低保存可靠性。


## 已接受的性能限制

本机隔离大图测试中，结果持久保存曾使宿主任务查询排队约298ms。用户已接受将其列为当前版本限制；这不是对所有磁盘/图片尺寸的延迟上限保证。程序仍先可靠保存再确认，不因该限制降低数据库同步级别。此限制不代表桌面停止刷新属于预期行为，也不替代真实长请求的原生体验验收。
