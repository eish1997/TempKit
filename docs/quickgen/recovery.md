# 可靠底座备份与恢复

本说明对应 2026-11-13 审查返修日常候选（exe SHA256 前缀 9B2A33B08A6A）。返修功能已通过隔离故障和三进程恢复验证，新增控件外观已由用户确认通过，记录见执行计划与native-acceptance.json。原19C09候选的真实现场迁移与备份历史保留；本次未运行生产现场。程序身份见随包构建信息。

## 数据与权威

- 默认配置目录仍为 `%APPDATA%\com.quickgen.desktop`；配置和封面继续由原配置服务管理。
- 新资源目录为配置目录下的 `resource-store`。`metadata.sqlite` 保存资源、任务 attempt、事件游标、场景 revision、结果放置记录及迁移标记，`blobs` 保存受管图片。
- `migration-backups` 保存切换前固定源快照，含旧场景图片正文、任务和当时的配置/封面备份。准备与验证不激活；场景、引用和 active 标记一起提交后，Rust 成为权威。
- 原 IndexedDB 留存，active 后不再写入。启动按持久 active 标记选择数据来源，不能通过删除标记或数据库来回退。
- `--isolated-data` 下的配置、资源及 WebView 数据全部在指定测试目录。测试目录不是生产配置目录，不应复制隔离标记到生产目录。

## 保存恢复副本

托盘“保存恢复副本”入口会先提交画板当前操作，再由宿主导出。入口及文件管理器打开行为已通过用户原生验收，最终候选的导出内容另经实际 WebView 副本演练核对。

导出目录位于 `resource-store/recovery-exports/recovery-…`，完成后打开该目录。副本包含：

- SQLite 一致快照 `metadata.sqlite`，经过完整性检查。
- 所有已登记资源的图片正文，包括仍有记录的退役资源。
- 原始迁移备份目录。
- `inventory.json`：资源清单、任务快照、场景、配置与封面备份。
- 最后才写入的 `manifest.json`：格式、数据库版本、文件 SHA256 及回退限制。

文件复制后逐一回读核对。导出过程中不会删除或改写原资源、场景或任务。没有 `manifest.json` 的目录是不完整导出，应保留用于排查，不能作为可恢复副本交付。空间不足、图片损坏或迁移备份不一致都会报错，不把缺失项静默跳过。

清单用于验证原始副本。不要先用应用打开唯一副本再校验哈希；打开数据库可能更新其工作状态。恢复演练应使用副本的再次复制件。

## 切换前回退

准备/复制/验证失败时，旧 IndexedDB 仍是权威。保留原目录及错误信息，修复具体缺失项后重试；稳定旧 ID 映射使已经提交的复制项可以复用。撤销准备只撤销未激活候选，不删除图片或独立备份。

## 激活后回退

旧程序只认识切换时留存的 IndexedDB，无法理解激活后新导入的图片、任务或移动。回退旧可执行文件不等于无损回退。

1. 保存并核对恢复副本，保留当前完整数据目录和当前程序。
2. 正常退出，等待退出前保存完成；保存失败时先处理错误，不强行结束来冒充保存成功。
3. 在独立目录演练副本恢复，核对图片可读、任务状态、场景位置、配置和新增资源清单。
4. 必须使用旧程序时，明确它只显示切换时的旧快照；保留新库供之后恢复和人工对照。

当前没有“把新库全部写回旧 IndexedDB”的逆向迁移器。不要删除新库、重置 WebView 或覆盖原目录来使旧版看似恢复正常。

## 恢复约束

同一资源库只允许一个写入服务。启动报告占用时先退出另一个实例。未知较高数据库版本或损坏数据库拒绝打开并保留原文件；不要降版本强开。

重启后 queued 任务继续排队；running/waiting_user 的未知结果转 interrupted，不自动重发；已有暂存输出的 finalizing 任务只恢复归档。成功 attempt 不重跑，显式重试创建新 attempt。当前执行器仅产生带“模拟结果”标识的合成图片，没有付费模型或真实 Harness 调用。


## 审查返修：保存失败与任务隐藏

归档失败会显示“结果保存失败”、错误详情和“重试保存”。错误随任务持久保存，关闭或重启不会清掉失败或再次执行模型；修复空间/文件问题后，重试保存只归档已有暂存输出，沿用同一attempt，执行次数不增加。归档成功后错误清除。没有失败记录的暂存输出仍可在启动时继续归档。

“取消”只用于尚未执行的排队任务；已经执行或正在保存的任务提供“隐藏”，不会取消执行、删除原图或丢弃结果。任务摘要的“显示隐藏任务”按钮可重新显示卡片，包括失败后的重试保存入口。宿主已受理任务的结果放置不依赖本地卡片是否存在。

图片上的移除按钮只移除画板中的图片实例。已放置结果的持久收据会保留，因此事件重放、WebView重载和程序重启不会把明确移除的结果再次插入；这不会删除用户原文件。
