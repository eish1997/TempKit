QuickGen是桌面上的临时收纳盒：服务高频、临时、快速取得结果的操作，让放入、处理、取出都方便。画板用于摊开查看和对比。当前支持图片交互；未来预设可连接模型、已有Agent和本地工具，通过统一、有类型的输入输出契约扩展。

**当前位置：可靠底座 R0—R4 已完成。资源、场景与模拟任务由 Rust 管理；真实现场已备份、迁移并验证退出重启，默认交付包已核对。真实模型、Agent 和 AI Gateway 尚未接入。**

放入仅收纳，有意拖到能力才执行；多图逐张排队，结果在原图旁继续使用。当前输出是模拟结果，不代表真实模型生成。沿用唯一quickgen-desktop入口与com.quickgen.desktop数据目录。

## 统一进度口径

- 当前单屏基线已收口；用户确认托盘打开/退出、桌面流畅及悬浮变淡。历史已通过测试保留，行为变更才补相关回归。
- 多屏/混合DPI、大量图片和长时运行不因单屏收口视为通过。W阶段保留的未验收分支见原台账，不倒改历史证据。
- Rust资源、模拟任务与恢复已接管正式画板；用户原生四项验收、真实迁移及重启核对通过。受控容量100张512×512图片、50任务、30分钟通过；更大规模与多屏仍待后续验收。
- 不再用旧的工作量百分比表示整体完成度；按基线和各阶段交付判断。

已确认后续支持在用户自己的Harness中一句话添加预设，先引用原Harness执行；通过独立连接与能力版本找到执行入口。R0已完成相关类型与模拟校验，具体Harness及接入方式尚未选定，真实导入/执行未实现。
