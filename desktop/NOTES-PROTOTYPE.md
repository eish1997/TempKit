# 桌面便签交互原型

运行：`desktop/src-tauri/target/release/quickgen-notes-prototype.exe`。
构建：在项目根目录执行 `desktop/scripts/notes-prototype.cmd build`。

本原型使用独立应用标识，内容仅存于进程内存，不读写正式应用配置和资源库。结束原型后内容清空。

体验顺序：
1. 点击新建，直接输入中文、多行文字。
2. 拖动顶部空白区域，拖动窗口边缘调整大小。
3. 点击置顶，切到其他应用检查遮挡关系，再取消置顶。
4. 点击 × 收起，从列表点击正文首行找回。
5. 新建第二张，检查独立窗口和内容。
6. 从列表窗口点击结束原型，确认后退出全部窗口。

本轮不包含持久化、删除撤销、正式主面板入口、多屏恢复。先确认编辑和窗口交互，再规划生产实现。
